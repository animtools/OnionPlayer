# OnionPlayer

> **動画から線画を抽出し、前後フレームを透過重ね表示（オニオンスキン）して動きを研究できるプレイヤー。**

実写やアニメの動画を読み込むと、輪郭線だけを抜き出して表示します。そこへ前後のコマを
薄く重ねると、体の各部がどう動いたか、どこでタメてどこでツメているかが1枚の絵として見えます。
作画の勉強、実写リファレンスの分析、自分のアニメーションの検証に使う道具です。

![オニオンスキン表示](images/40_onion_hero.png)

---

## デモ・スクリーンショット

**線画抽出** — 元の映像から輪郭線だけを取り出します。

![抽出方式の対比](images/111_extract_shader.png)

**静止部の除去** — 動かない背景の線を落とし、動いたものだけを残します（固定カメラ素材向け）。

![静止部の除去](images/141_static_on.png)

**オニオンイコライザ** — 層ごとの濃さを縦棒で直接いじれます。等間隔のゴーストは
そのままスペーシングチャートとして読めます。

![オニオンイコライザ](images/50_onion_equalizer.png)

## ダウンロード

[Releases](https://github.com/animtools/OnionPlayer/releases) から最新の
**OnionPlayer-v0.1.1-portable-x64.zip** を取得し、好きな場所に解凍して
`OnionPlayer.exe` を起動してください。インストール不要です。

- **ポータブル**：設定・キーフレーム・ML モデルは exe と同じフォルダの
  `OnionPlayerData\` に入ります。フォルダごと持ち運べます
  （ライセンス認証だけは付いてきません。移した先で認証し直しになります）。
- **未署名**のため、初回起動時に SmartScreen の警告が出ます。配布ページに
  VirusTotal のスキャン結果と SHA-256 を併記しています。

## 主な機能・特長

- **2種類の線画抽出** — 高速な**シェーダ抽出**（Sobel / DoG / XDoG）と、
  より綺麗な線が出る **ML 抽出**（Lineart / OpenSketch）。
- **オニオンスキン** — 過去・未来のコマを層として重ね、層数・間隔・濃さの減衰を自由に設定。
  イコライザで層ごとに直接調整でき、プリセットとして保存できます。
- **キーフレーム基準** — 打ったキーフレームの区間を等分して層を配置します。
  等間隔（コマ数基準）との切り替えが可能です。
- **静止部の除去** — 背景モデルと輝度が一致する画素の線を落とし、動いたものだけを残します。
- **めくり・パラパラ** — 層をコマ送りでめくる、指定 FPS で自動送りする。
- **重ねて表示 / 並べて表示** — 1枚に重ねるか、独立したペインに並べるか。
- **区間ループ・コマ送り・秒送り・スクラブ** — 見たい数コマを繰り返し観察できます。
- **方眼**・**集中モード**・**書き出し**（PNG の保存・クリップボードへのコピー・層ごと）。

### 動作環境

- **Windows 10 / 11（x64）**
- **WebView2 ランタイム**（Windows 11 は標準搭載。10 では未導入の場合に案内が出ます）
- ML 抽出は GPU（DirectML）で動き、利用できない環境では CPU にフォールバックします。
  モデル（約 241 MB）は初回利用時にアプリ内からダウンロードします。
